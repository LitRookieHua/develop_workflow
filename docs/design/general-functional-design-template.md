## 五、 异常处理、安全性与高可用设计 (Error Handling & Robustness)
> 💡 *高质量设计的关键在于如何应对"墨菲定律"（凡是可能出错的事必定会出错）。*

| 异常 / 边界场景 | 潜在系统风险 | 防御、降级与容错策略 |
| :--- | :--- | :--- |
| **下游服务超时/雪崩** | 线程池被打满，拖垮整个主应用 | 引入 **Circuit Breaker (熔断降级)** 机制，超时（>500ms）后快速失败，返回默认兜底数据。 |
| **高并发下的重复提交 (幂等性)** | 产生脏数据或重复扣款 | 引入分布式锁（Redis Distributed Lock）或基于业务唯一流水号（Idempotency Key）进行防重校验。 |
| **非法输入或恶意攻击** | 触发 SQL 注入、越权访问或内存溢出 | 在入口处做严格的参数白名单校验与鉴权（RBAC），过滤危险字符。 |
